# 🤖 JARVIS

JARVIS is a personal AI assistant designed for Windows.

It helps users interact with their computer using voice commands, automate tasks, control applications, and perform various useful actions.

## ✨ Features

- 🎙️ Voice commands
- 🖥️ Windows control
- 🌐 Browser control
- ▶️ YouTube control
- 📂 File and application management
- ⚙️ Task automation
- 🔊 Media control
- 🧠 AI assistant features
- 🎨 Modern user interface

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/aliyhacker/jarvis.git
cd jarvis
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run JARVIS:

```bash
python main.py
```

You can also use the included Windows batch files:

```text
setup.bat
BASLAT.bat
```

## 🖥️ Requirements

- Windows
- Python 3.x
- Internet connection for online features
